# Project Memory

## Core
Quiet luxury design: Navy/Gold/Off-white, Playfair Display (headings), Inter (body), sharp edges.
APOGESP is independent from SP City Hall. No govt roles/titles in structure.
Tone: Institutional, efficient, technical. No union language or promotional slogans.
APPGG é COLABORADOR, nunca protagonista. Usar "colaborou/contribuiu/participou", não "fez/liderou/criou". Sempre dentro de PAIs e em parceria com outras carreiras e administração superior.
UI Simplifications: No forms in contact, no login for Associate Area, no recent pubs on home.
